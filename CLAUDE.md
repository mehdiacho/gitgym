# GitGym
Vite + React + TS + motion. Simulated git and GitHub in src/engine (pure functions); lessons in src/lessons.ts form one continuous project.
- npm run dev, npm test, npm run build:portfolio (base /projects/gitgym/).
- Changing a lesson's prep or hints changes every later lesson: run npm test (journey test).
- SVG colours from CSS vars go in style, not presentation attributes.
- Read docs/HANDOFF.md first. No AI attribution in commits.
